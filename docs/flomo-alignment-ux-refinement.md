## 1. flomo 取证结论（做方案前先立靶子）

从 flomo 线上 CSS（`resource.flomoapp.com/flomo-web/css/index.*.css`，组件 scope `data-v-579161f5`）还原的 memo 卡片结构：

```
div.display
├── div.header（高度 20px）
│   ├── a.time        ← 时间戳本身是链接，纯文本样式，hover 仅颜色加深
│   └── div.tools     ← 右上操作按钮组（编辑/删除/工具菜单），hover 淡入，移动端常显
└── div.content       ← 纯正文
```

四条可迁移的交互判据：

1. **卡片头部只放两类东西**：身份信息（时间戳）与真实可用的操作。不存在的功能不占坑——flomo 行首**没有任何占位图标**，也没有时间轴隐喻。
2. **置顶不靠图标**：置顶是独立呈现（置顶区/标签），不往普通卡片头部塞图钉。
3. **动作跟着指针走**：低频操作 hover 浮现（`@keyframes opac-579161f5` 淡入），常驻的只有右上 `⋯`。
4. **批量选择是独立模式**（`.multiSelect`），不靠卡片常驻勾选圈；选中态用内描边+底色表达。

## 3. 目标信息架构：顶栏接管范围切换，侧边栏只做导航

### 3.1 顶栏（改 `App.tsx:551-613`）

flomo 式三件套：

```
┌──────────────────────────────────────────────────────────┐
│  全部笔记 ▾                          [ 🔍 ⌘K 搜索 ]      │
└──────────────────────────────────────────────────────────┘
```

- **左：范围下拉**（新组件 `ScopeSwitcher`）。一级项 = `flaremo-explorer.tsx:124-149` 的 spaceItems 上移：全部笔记 / 个人笔记 / 团队笔记（无团队时团队项隐藏，沿用现有逻辑）。当前选中态大字显示 + 计数徽章。
- 下拉**底部加分隔线**放二级低频视图：归档 / 回收站（即 `navItems` 的 archived/trashed）。时间线（`view=all`）是默认态，不单独出现——范围选中即时间线。
- 搜索框、路由 search 参数（`?space=&view=`）全部沿用现状，只改入口位置，不动数据层。

### 3.2 侧边栏瘦身后 4 段（改 `flaremo-explorer.tsx`）

1. **Logo + 账户动作**（铃铛/更新/设置，现状保留）
2. **统计三格**（记录/标签/连续天数）——保留，但热力图降级：
   - **删掉**热力图/日历双视图切换器与 `TIME_VIEW_STORAGE_KEY`（C8）；
   - 可选保留一条**迷你本月活跃条**（7×4 缩小版，点击跳 `/calendar`）；
   - 迷你日历面板（MiniCalendarReminders/MiniCalendarPanel）随切换器一起移除，日程归 `/calendar`。
3. **功能导航**：每日回顾 / 随机漫步 / 速记 / 记忆 / 日历 / 项目（现状 340-394 平移，无变化）
4. **标签树**（现状保留）

侧边栏预期可点目标从 >25 降到 ~13，高度减少约 300px。

**不做**：flomo 的排序/来源/多选/导出下拉（图片2）暂不引入——本项目导出/导入已有固定位置（页脚），多选模式暂无需求，不要为了像而加。

## 6. 权限与分享分离（P1，核心决策）

### 6.1 新模型

- **权限 = 记录的属性**（谁能看）：从分享弹窗中移除，入口统一为 ⋯ 菜单「可见性」子菜单（§5）与发送框可见性 chip（§8），两处同构。切换为公开时自动创建只读 Share（`shareMutation` 逻辑不变，只是不再以"分享"面目出现）；降回私人时删除 Share。
- **分享 = 输出动作**（给别人什么形式）：⋯ 菜单「分享…」只剩两种输出：
  1. **复制链接**：按当前权限给只读链接，一键复制，**不再弹模态框**；
  2. **生成图片卡片**：弹模态框（§7）。

### 6.2 连带改动

- 现分享弹窗（`memo-card.tsx:536-618`）整个删除，`saveSharing`/`shareVisibility` 状态随之清理；
- `onUpdate` 权限变更走 `updateMutation`（现成），公开/私人切换时联动 `shareMutation`——需要 `use-memo-mutations.ts` 加一个 `setVisibility` 包装（含乐观更新）；
- **边界**：个人笔记没有公开链接输出项时，「复制链接」置灰并提示"公开后可分享"——不做静默提权（克制：不给用户意外扩大权限的操作）。

## 7. 图片卡片分享生成器（P2，新能力）

flomo 的「生成分享图片」：大预览 + 底部模板横滑（日签/票根/手札/备忘/素白/空笺），卡面含日期、正文、品牌落款、`N 条笔记 · N 天` 与像素点缀。

**落地设计**：

- 新组件 `components/share-image-dialog.tsx` + `components/share-image-templates/`（每模板一个纯展示组件）；
- 基座复用 `memo-snapshot-card.tsx` 的只读渲染思路，模板组件按「日期 / 正文 / 落款」三段结构各自发挥；
- 导出：`html-to-image`（或等价 toPng）前端出 PNG，起步不依赖后端；数据（`N 条笔记 · N 天`）来自现有 `getMemoStats`（`stats.counts.total` + `stats.active_days` 已有）；
- 模板首发 3 个（素白 / 日签 / 票根风格），后续按需加——克制不放肆，不做 6 个占位模板；
- 深色模式：跟随主题各出一版，预览所见即所得。

**明确不做**：像素统计格（flomo 的 heatmap 点阵）V1 不抄——数据量小时它反而是噪音，留给 P2+ 观察。

## 11. 风险

- **R1** 范围切换上移后，`?space=` 直达链接（外部分享/收藏夹）必须保持可用——实现时以 URL 参数为唯一真源，ScopeSwitcher 只是渲染入口；
- **R2** 移动端抽屉（Sheet）复用同一 explorer，减重后移动端自动受益，但顶栏下拉在窄屏需保证 ≥44px 触达高度；
- **R3** 删除分享弹窗是行为变化：已有"从弹窗里改权限"习惯的用户需要一次学习成本，缓解办法是 ⋯ 菜单「可见性」置顶显示当前值。
