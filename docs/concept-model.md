# 产品概念模型

- 日期：2026-09-17
- 状态：定稿。D2「记录待办单向升级」与 D3 命名统一已落地（main `bf7dad9`）。
- 性质：全产品的概念判决书——任何新功能必须归属两个实体之一，或明确标注为视图/属性；说不清归属的不进入产品。

## 一句话

**两个核心实体（记录、任务）、一道门（转为任务）、其余全是视图。**（2026-09-19 增补：文章是面向公开发表的第三实体，见下文与 `article-publishing-design.md`；记录与任务的心智与数据规则不变。）

## 三个平面

「用户感觉是一个东西」和「数据上是两张表」并不矛盾——它们是三个平面各自的最佳实践：

| 平面 | 规则 |
|---|---|
| 心智平面 | **一个东西、两种状态**：用户写下的那句话，可以是记录，也可以是行动。用户不需要知道底下有几张表。 |
| 数据平面 | **一个事实一个主人**：文本属 `memos`，行动属 `tasks`；跨域只有一道显式桥。 |
| 视图平面 | **视图是同一份数据的滤镜**，不是新概念。 |

两条防污染纪律：

1. **数据的"二"不泄漏到心智**——界面上不出现"请同时管理两套系统"的事实。
2. **心智的"一"不泄漏到数据**——不拿正文当任务事实源，不把任务状态写进 Markdown。

## 两个实体

### 记录（memo）—— 无状态的记录

- 定义：写下来的内容。无状态、不可「完成」、以时间戳为骨。
- 形态：文本、图片、音频与文稿、分享、回顾素材；capture / 语音 / 上传只是它的输入方式。
- 判据：**它不能被「完成」。**

### 任务（task）—— 有状态的行动

- 定义：要做的一件事。有状态（todo / in_progress / done）、可完成、以 `dueAt` 为骨。
- 归属：可挂项目（`project_id` 可空），owner 私有（见 `product-requirements.md` 决策记录 D4）。
- 判据：**它可以被「完成」。**
- 「日程」= 有日期的任务，**同一个实体**：无日期 = 待办/收件箱；有日期 = 日历上的日程。`dueAt` 是日程唯一事实源（`eventAt` 永不复活，见 R10）。

## 那道门：转为任务

记录与任务之间**只有一道门**：把记录里的一行**显式转为任务**。当前实现（D2 单向升级）：

- 记录渲染时，任务行（对可编辑者）悬停出现「转为任务」入口；点击即建任务——标题取行文本，`source_memo_id` 回链原记录，不带日期（日期到任务侧再排，排了日期就上日历）。
- 任务卡上显示来源记录回链；记录行上暂不显示任务状态。
- **勾选 ≠ 建任务**：勾选只是改写这行记录本身（`- [x]`）；不自动识别、不批量创建、不迁移存量。
- 任务侧（完成 / 改期 / 删除）不回写记录正文；记录侧删行、删整条记录也不影响已建任务——**任务一旦建立即独立承诺**，链接失效时读取降级，不静默销毁。

## 视图与属性（不是概念）

| 名称 | 是什么 |
|---|---|
| 日历 | 任务按时间看（+ 当天记录的只读层） |
| 今天 / 收件箱 | 任务的有日期视图 / 无日期视图 |
| 项目 | 任务的主题容器（可空归属；**不做第二调度事实源**） |
| 看板 | 任务按状态看 |
| 往年今日 / 记忆漫游 | 记录的读法 |
| 空间 / 团队 / 标签 | 作用域与横切属性 |
| capture / 语音 / 上传 | 输入方式，不是概念 |

## 红线（防复发）

1. `dueAt` 是日程唯一事实源；不新增事件/日程实体。
2. 记录永不携带任务状态字段；任务状态永远住在 `tasks` 表。
3. 不双向回写正文；跨界只有「转为任务」这一道显式动作。
4. 不自动转化、不批量迁移存量记录。
5. 不做"一切皆对象"的统一大表——两个实体各有生命周期、权限与索引。

### 文章（article）—— 面向公开发表的编辑物（2026-09-19 定案）

- 定义：写给「公开发表」的编辑物。有标题、slug、草稿→发布状态机、发布时间；**判据：它有自己的公开发布契约**。
- 与记录的边界：记录是流式的、以时间戳为骨、私有/分享链接（不可枚举）；文章以内容为骨、发布即**可枚举公开**（进 sitemap/RSS，搜索引擎可收录）。发布语义相反是分表的根本原因，不是「记录的另一种视图」。
- 不做「记录→文章」的单向门（与转为任务不同：任务桥是状态转换，文章是发表语义）；备选低成本形态是「复制为文章草稿」（P2）。
- 见 `article-publishing-design.md` 与决策记录。

## 术语

- **任务**：全语言统一一个词（zh「任务」；「日程」不再作为实体名，仅在「排上日程」这类动词性/容器性表达中出现）。
- **记录**：zh UI 用语「记录」（产品讨论与文档中亦写作 memo / 笔记，指同一实体）。
