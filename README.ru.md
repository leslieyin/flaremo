## 💡 Почему FlareMo?

Сервисы вроде Flomo и Memos доказали ценность быстрой фиксации мыслей и ленты заметок без отвлекающих факторов. Однако самостоятельный хостинг таких решений обычно требует аренды VPS, настройки Docker и PostgreSQL, написания скриптов бэкапа и постоянного страха перед поломкой жесткого диска.

FlareMo предлагает принципиально другой подход: **Можно ли получить отказоустойчивую, глобально ускоренную базу знаний, доступную 24/7 без серверов и сложного обслуживания, используя лишь бесплатный аккаунт Cloudflare?**

Ответ — да:

- **Истинный Serverless**: Код и статический фронтенд исполняются на более чем 300 пограничных узлах Cloudflare по всему миру с откликом в считанные миллисекунды.
- **Корпоративная надежность из коробки**: Cloudflare D1 хранит заметки и метаданные, а мультирегиональное хранилище Cloudflare R2 надежно держит вложения.
- **AI-Native архитектура**: Встроенный протокол MCP и долгосрочная память «Agent Memory» позволяют ИИ-ассистентам (Claude, Cursor, Codex, ChatGPT) хранить и обновлять ваш рабочий контекст.
- **Приватность и командная работа**: По умолчанию это изолированное личное пространство, которое при включении командного режима мгновенно становится рабочим пространством с ролями и тремя уровнями видимости.

## ✨ Ключевые возможности

### 1. Мгновенная фиксация и вдохновляющие обзоры
- **Пишите сразу**: Хронологическая лента в виде карточек, поддержка тегов, рендеринг Markdown/GFM, предпросмотр изображений и аудио.
- **Быстрый полнотекстовый поиск**: Индексация SQLite FTS5 с поддержкой фильтров (`has:attachment`, `is:pinned`, `before:YYYY-MM-DD`, `after:YYYY-MM-DD` и др.).
- **Векторный семантический поиск**: Поиск по смыслу на базе Workers AI embeddings и индексов Vectorize с прозрачным возвратом к FTS5.
- **Активация воспоминаний**: **Ежедневный обзор** («В этот день»), **Случайная прогулка** (навигация по графу тегов и связей) и рекомендации похожих заметок.
- **История версий**: Наглядное сравнение изменений и восстановление любой ревизии в один клик.

### 2. Долгосрочная память ИИ и нативный MCP
- **Agent Memory**: Через эндпоинт `/memory/mcp` ИИ-агенты могут читать и записывать долговременную память (предпочтения, решения, ограничения, уроки).
- **Контроль человеком**: На странице `/memory` вы можете просматривать, подтверждать, закреплять или исправлять зафиксированные воспоминания.
- **Открытая экосистема**: Стандартный эндпоинт Streamable HTTP MCP (`/mcp`) для программного управления заметками.

### 3. Командная работа и 3 уровня доступа
- **Роли**: `owner`, `admin`, `member`. Одноразовые ссылки активации позволяют участникам самим задавать пароли без передачи их администраторам.
- **3 уровня видимости**:
  - 🔒 **Приватно**: Видно только автору.
  - 👥 **Команда**: Доступно для чтения активным участникам команды.
  - 🌐 **Публично**: Публичный доступ по ссылке с возможностью отзыва.
- **Безопасное удаление участника**: При удалении пользователя его личные данные физически очищаются, а командные и публичные материалы сохраняются.

### 4. Офлайн-режим и возможности PWA
- **Устанавливаемое PWA**: Установка на рабочий стол или смартфон с ощущением нативного приложения.
- **Надежная синхронизация**: Черновики сохраняются локально; созданные офлайн заметки отправляются по порядку сразу при восстановлении связи.
- **Голосовые заметки в реальном времени**: Страница `/capture` со потоковым распознаванием речи в текст (ASR).

### 5. Безопасность Better Auth
- **Надежные сессии**: `HttpOnly`, `SameSite=Lax` куки для браузера; отзываемые токены `memos_pat_` для скриптов и MCP.
- **Строгая проверка Origin**: Защита от межсайтовых атак при всех модифицирующих запросах.

### 6. Совместимость с экосистемой Memos
- **Совместимость с Memos API**: Поддержка эндпоинтов `/api/v1/*` и спецификации OpenAPI.
- **Поддержка сторонних приложений**: Прямое подключение мобильных клиентов, таких как Moe Memos.
- **Импорт и экспорт**: Быстрый перенос архивов Memos и flomo с гибкой обработкой конфликтов.

## 🚀 Быстрое развертывание за 5 минут

### Способ 1: С помощью ИИ-агента (Рекомендуется)

Передайте репозиторий автономному агенту (Claude Code, Cursor Agent, Codex) вместе с [docs/agent-deploy.md](./docs/agent-deploy.md):
> «Пожалуйста, разверните FlareMo в моем аккаунте Cloudflare согласно docs/agent-deploy.md».

---

### Способ 2: Ручное развертывание в 3 шага

#### 1. Создание ресурсов
```bash
pnpm exec wrangler whoami
pnpm exec wrangler d1 create flaremo
pnpm exec wrangler r2 bucket create flaremo-attachments
```

#### 2. Настройка конфигурации и секретов
```bash
cp wrangler.jsonc.example wrangler.jsonc
# Укажите database_id и FLAREMO_PUBLIC_URL в wrangler.jsonc
pnpm exec wrangler secret put BETTER_AUTH_SECRET --config ./wrangler.jsonc
pnpm exec wrangler secret put FLAREMO_BOOTSTRAP_SECRET --config ./wrangler.jsonc
```

#### 3. Публикация
```bash
pnpm verify
pnpm deploy:dry-run
pnpm deploy
```
Перейдите на страницу `/setup` на вашем домене и введите `FLAREMO_BOOTSTRAP_SECRET` для создания учетной записи владельца.
